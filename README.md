# Banan Menu for Hellraiser: Revival

A community mod menu for the Windows Steam release of Clive Barker's Hellraiser: Revival.

This source snapshot starts from the locally verified Banan Menu 0.4.16. Version 1.0.0 is in development.

Based on [Ketamine Menu](https://github.com/literalynn/Hellraiser-Revivals-Ketamine-Menu), upstream commit `3b4ba3efc7ecc8c01f2d59b67ff64e4c3fda642f`. Upstream copyright and the MIT license are preserved in LICENSE. Dependency notices are in THIRD-PARTY-NOTICES.txt.

Game files, user saves and credentials are not part of this repository.
