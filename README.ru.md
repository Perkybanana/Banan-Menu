# Banan Menu для Hellraiser: Revival

**1.0.0-dev.7 — кандидат в разработке для Windows-версии игры в Steam, а не проверенный стабильный релиз 1.0.0.** В dev.3 панель не работала. В dev.4 враги были невидимы и бездействовали; добивание Genesis после «Убить врагов поблизости» привело к сбою из-за отсутствующей модели. В dev.5 добавлены полная инициализация через игровой менеджер врагов и проверки готовности модели. Dev.6 исправил чтение метаданных массивов, но проверка штатных параметров по-прежнему блокировала запрос до вызова игрового спавна. Dev.7 после проверки отражённых типов явно отключает необязательное переопределение кривой слуха в сохранённых параметрах и записывает поле и этап отказа в журнал. Приёмка в игре ещё не выполнена. Поддерживается штатный выбор эпизода/главы; начало с произвольной контрольной точки не входит в текущий объём работ.

## Что есть в исходниках

- Игрок и бой: здоровье, урон, боеприпасы, прочность, прицеливание и способности Genesis Configuration.
- Движение и мир: полёт/noclip, скорость/прыжок, сохранённые позиции, телепортация к загруженным контрольным точкам уровня, скорость времени, управление ИИ, свободная камера, FOV и скрытие HUD.
- ESP для врагов, предметов, контейнеров и точек сохранения.
- Инвентарь: деньги, точные количества шести переносимых материалов (0..9999), каталог предметов, избранное, явные наборы выдаваемых предметов и локальные профили настроек.
- Текущие цели, уровень магазина и достижения Steam; штатный выбор глав сохранён. Можно настроить язык, масштаб и клавиши.
- Три защищённые закладки свободной камеры в пределах текущего сеанса. 25.10.2026 пользователь принял в dev.2 сохранение вида, перемещение/поворот и восстановление на Chapter5, а отдельно — блокировку восстановления вида другой карты после перехода через меню/выбор главы без вылета. Остальные слоты, FOV и варианты со смертью проверены не полностью.
- «Мир» → «Создание врагов»: адский упырь, взрывающийся упырь, камбион, культист и бегун, количество 1–5 и явная кнопка создания. Меню остаётся открытым. При нажатии загружается только выбранный тип; первая загрузка может ненадолго задержать игру. Штатный менеджер размещает врагов впереди персонажа с промежутками. Запрос ожидает до 15 секунд; статус считает только врагов с меткой этого запроса, завершённой инициализацией и загруженной моделью. Отсутствующие настройки, неготовая модель и смена уровня дают отказ или частичный результат. «Убить врагов поблизости» пропускает врагов с неготовой инициализацией или моделью. Это не подтверждает работу ИИ, боя или добиваний.

Доступность зависит от игрока, карты и поддерживаемых штатных интерфейсов игры. Наборы запрашивают выдачу предметов и подчиняются существующему поведению вместимости/выбрасывания; это не атомарное применение экипировки. Телепортация к загруженной контрольной точке не создаёт полное сюжетное состояние. Отдача, скорость атак и видимость рук исключены из текущего объёма работ по решению владельца. Необычное оружие и возможный вырезанный контент исследуются; их работоспособность не подтверждена.

## Установка, обновление и удаление

1. Закройте игру. Через Steam откройте установленные файлы игры, затем `Hellraiser/Binaries/Win64`.
2. Сделайте резервную копию имеющегося модифицированного `winmm.dll`. Из архива скопируйте **только `winmm.dll`** в эту папку, рядом с исполняемым файлом игры. Документацию и лицензии сохраните для справки.
3. Запустите игру обычным способом через Steam. Меню открывается и закрывается клавишей **Insert** или **F8**.

При обновлении закройте игру, сохраните копию прежней DLL и замените только `winmm.dll`. Сохраните `BananMenu.ini` (настройки) и `BananMenu.presets` (профили, избранное и наборы). В архиве этих файлов нет. После изменения материалов переоткройте штатный инвентарь, чтобы обновить отображение.

Для удаления закройте игру и удалите DLL мода либо восстановите прежнюю DLL из резервной копии. Настройки и наборы можно оставить для повторной установки; их удаление необязательно. Для отката обновления верните сохранённую DLL мода при закрытой игре.

## Сборка и упаковка

Нужны Windows x64, инструменты MSVC C++/MASM и CMake 3.25 или новее. Учётные данные, сохранения и установленная игра для сборки и офлайн-тестов не требуются. При первой конфигурации CMake загружает закреплённые архивы Dear ImGui и MinHook с проверкой хешей. Во время работы игры меню не делает веб-запросов.

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release --parallel 1 -- /nodeReuse:false
ctest --test-dir build -C Release --output-on-failure
powershell -NoProfile -File scripts/package.ps1 -BuildDirectory build -OutputDirectory packages
```

Упаковщик включает обычную Release DLL, документацию и лицензии по фиксированному списку. Результат: `BananMenu-1.0.0-dev.7-win64.zip` и JSON с хешами, размерами, коммитом исходников и версией кандидата. Перезапись существующих файлов запрещена без явного `-Force`. Перед установкой сравните SHA-256 извлечённой DLL с манифестом. Сверяйтесь с примечаниями к устанавливаемому кандидату и [записанными результатами сканирования](docs/VERIFICATION.md). Результат относится только к точному указанному хешу DLL; другая сборка требует собственной проверки. Сканирование не гарантирует отсутствие любого вредоносного кода и не заменяет приёмку в игре.

Windows workflow собирает, тестирует и загружает артефакт разработки без публикации GitHub Release. При изменениях выполняйте операции с игрой в игровом потоке, передавайте отображению копии состояния и храните пользовательские RU/EN строки в `src/lang.cpp`. Запускайте указанные проверки и описывайте фактическую проверку в игре.
